# Hypr Dots

Modern Hyprland + UWSM dotfiles for Arch Linux with a clean Wayland workflow.

- “Minimal Wayland desktop powered by Hyprland.”
- “Fast, keyboard-driven Arch Linux workflow.”
- “Rice once, use forever.”
- “Modular Hyprland setup with UWSM integration.”

## Installation

To clone the repository along with all the submodules run:-

```bash
git clone --recurse-submodules https://github.com/Sain-Biswas/hyprdots.git
```

OR, if you have cloned the repository without submodules run this to pull submodules:-

```bash
git submodule update --init --recursive
```
